# Contributing

Focus on reproducible improvements to learning, accessibility, reasoning experiments, data flow and clear visual explanations. Describe what changed, how it was tested and practical limitations. Preserve the author's faith teaching respectfully and keep sourced factual material attributable.

Never commit credentials, cookies, browser profiles, saved conversations, private source accounts or personal runtime data. Add tests for changed calculation behaviour. Avoid presenting animation, random strings or greater processing activity as proof of general intelligence.

The releasing author's owned contributions are CC0. Your contribution must identify any separate license and must not include material you lack permission to share.
