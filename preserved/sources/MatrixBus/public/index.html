THE SIGNAL BEHIND THE MATRIX

Code in motion.

Every running Python and Java interpreter contributes to the rain. Start an app anywhere on this computer; it appears automatically.

01CPU → speed

Busy processes send characters down faster.

02Memory → density

Larger memory footprints create longer, denser trails.

03I/O → glow

Reads and writes brighten the heads of the rain.

Python is mint green; Java is amber. CPU is normalized across all logical cores. Process I/O includes Windows read/write I/O; network telemetry is system-wide. Unknown counters show “—”. Dim idle rain is ambient; it does not represent measured activity.

The console runs real commands as your Windows user. It supports non-interactive commands, with a two-minute time limit and Stop button. Use Start-Process for apps that should keep running. Each command gets a fresh shell.
