PROGRAM CONNECTIONS

Connect Python & Java.

Discovery monitors running Python and Java processes. To exchange messages, the program must run a Genesis connector.

  1. Open the app folder.

    Use the connectors folder supplied with AI Genesis Node.

  2. Try the included examples.

    Run either command from the app folder:

    python connectors/python_example.py
java connectors/GenesisConnector.java

    Each example replies to messages. Replace its handler with your program's own logic.

  3. Select the connected program.

    It appears here with an “I/O ready” label. Send it a message and read the response.

Existing programs can be monitored immediately. Their input/output cannot be attached retroactively unless they already expose a connector.

The local connector credential is in data/connector-token. The examples read it automatically. No program messages are sent to AI providers automatically.
