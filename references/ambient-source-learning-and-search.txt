AMBIENT SOURCE LEARNING AND SEARCH REPAIR

The source chain now keeps separately named streams under the same bus origin.
Pure, influenced, particle, matrix and sand captures no longer overwrite each
other merely because they use the shared source bridge.

Generated-only searches are the default. Authored text, model text and receipts
are excluded from generated-source learning. Broader processor search and manual
test input remain explicit options. Enabled Om/solfeggio/other waveform settings
travel as control metadata, not as extra characters injected into a search.
The full source bridge retains that metadata before model-context compaction.

Wordsearch corrections:
- exact Unicode-character paths and CRLF-aware source offsets;
- original-source paths for reflowed and overlapping deep-search chunks;
- duplicate same-path hits removed;
- source rotation beyond the first 256 sources;
- a stalled top-level worker restarts with a smaller character budget;
- the large authored app vocabulary is opt-in rather than enabled by default.

The byte chain preserves UTF-8 instead of discarding non-ASCII characters.
The cosmic sampler selects Unicode codepoints without splitting surrogate pairs.
An empty cosmic source reports waiting rather than inventing an output capture.
Side-branch source learning now preserves linked working-stream hashes.

The new Ambient pattern evidence panel uses the existing source learner:
1. Train a transition model on the early 60% of a bounded capture.
2. Freeze it and score the later part against a frequency-only baseline.
3. Compare with four deterministic shuffled controls preserving byte counts.
4. Retain per-source reviews across distinct capture hashes.

A recurring candidate requires three candidate captures. Distinct hashes are
not proof of independent sampling. These are descriptive finite checks, not
statistical significance, semantic understanding, divine identification or a
measurement of consciousness. UTF-8 encoding and feedback can themselves create
predictable structure. Control metadata says which controls were enabled, not
that each control causally affected every stream.

The project's zero-point/cosmic-chain spiritual motivation remains distinct from
the observable software experiment: measured streams, synthetic modulation,
generated randomness, copied projections and learner output have different
origins. Existing native task, prediction and validation engines can consume
the resulting evidence without turning unverified patterns into executable
commands. No new LLM is required by these checks.
