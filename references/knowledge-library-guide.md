# Shared knowledge library

The Intelligence Engine thinking panels now include a searchable Knowledge library. Native chat accepts `knowledge library` for coverage or `library: TERM` for definitions. Native work retrieval automatically supplies relevant records to model context.

Coverage: 602 Pygments formats and their exported lexical patterns; installed Python builtins, AST structures and standard module names; installed PowerShell cmdlet names and parameters; command effect summaries; 29 major human-language grammar orientations; computing and linguistic foundations.

Records retain their source and capability level. Language profiles are compact orientations, not complete dictionaries or grammars. Lexical patterns support recognition; supported parsers and existing tests establish syntax and behaviour. Reference ingestion does not modify model weights. Commands remain definitions until explicitly invoked through the app's existing work tools.

Pygments-derived records retain the bundled Pygments BSD licence in vendor-language. Python structures are runtime introspection. Human-language profiles and foundations are authored summaries. Source links provide further study; linked material has not been wholesale copied or ingested.

Sources: https://pygments.org/docs/lexers/ ; https://docs.python.org/3/library/ ; https://learn.microsoft.com/powershell/ ; https://universaldependencies.org/
