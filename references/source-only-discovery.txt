SOURCE-ONLY STOCHASTIC DISCOVERY

Two additional areas beneath the existing searches: dictionary-free character groups and consecutive learned-token sequences. Discovery does not import a word list, pretrained language model, prayer text, Llama conversations or authored stage traces.

Eligible built-in streams: initial generated pre-filter ASCII; influenced post-filter ASCII; Unified Flux generated bit state and matrix glyphs; the random selector's generated occupied grid; generated-only Matrix rain, probability-cloud and sand projections; actual logic-cube stochastic input/output bits. The Matrix capture follows pool-index provenance and excludes characters appended from waveform descriptions or other text. Influence on generated values is retained; copying authored text into the source corpus is excluded. Whole-app encoded text grids and authored continuum trace strings remain in the older searches, not this source-only search.

The worker counts raw character groups along eight straight grid directions and bounded turning-neighbour walks. It learns a recurrence-based token inventory from the current capture, then segments the same raw characters greedily. Consecutive token blocks preserve original order and characters. These blocks are not grammar-classified natural-language sentences. Symbol frequencies and empirical next-character transitions are also retained. No semantic meaningfulness test is used. A selected group's original cell path is highlighted in the visual grid.

Defaults: 0.5-second requested interval; 16,384-character rapid budget; no overlapping discovery passes. Larger budgets are selectable. Partial sources rotate through explicit overlapping ranges; coverage records actual scanned ranges. Up to the selected row limit is retained; 100 rows per field are displayed; JSON export contains retained results. Requested intervals do not guarantee completion time.

Bus: authenticated local ambient listener, default 8800. Targets stochastic-discovery and stochastic-sequences. Input event kind is input. Payload is {name, text, stochastic:true, predefined_text:false, contains_model_text:false}. Source flags describe sender-declared provenance for external streams. Own result broadcasts are excluded from discovery to prevent feedback. Outputs are bounded summaries with raw pattern and sequence examples. Restart an already running app to register the new targets.
