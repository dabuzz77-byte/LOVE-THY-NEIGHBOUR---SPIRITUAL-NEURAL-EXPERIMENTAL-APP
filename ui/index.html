What the total processing display measures

The bits encode a selected runtime snapshot, not every bit in the computer. Processing index = 35% mean field magnitude + 25% queue occupancy + 20% completed research-topic coverage + 20% presence of a pipeline receipt. The line is an exponential moving average (80% previous, 20% current); it displays the app’s activity over time. Scrolling and colour are decorative; digits come from snapshot bytes.
